# Webcraft

A beginner-friendly web programming class project built with HTML and CSS.

## View the project

Open `f.html` in a web browser to view the responsive FirstWeb landing page.

## Project files

- `f.html` - Main page with embedded styling.
- `fristclass.html` - Original class page.
- `fristclass.css` - Stylesheet for the original class page.
- `b1.jpg`, `bestie.jpg`, `simin.jpg` - Image assets.
